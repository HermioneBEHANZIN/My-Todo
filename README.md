My Todo est une application web complète de gestion de tâches personnelle conçue pour être simple, rapide et intuitive.

Fonctionnalités :

Ajout, modification et suppression de tâches.

Marquage des tâches comme effectuées.

Filtres d'affichage (Toutes, En cours, Terminées).

Sauvegarde des données en local (LocalStorage).

Technologies utilisées : HTML, CSS, JavaScript.
